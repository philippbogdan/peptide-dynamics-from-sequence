# The evidence behind the numbers

[headline.json](headline.json) is the numerical entry point. [../reproduce.py](../reproduce.py) recalculates its state-based comparisons from the saved paths; the diagnostic experiments and timings are read from their saved records. [Definitions and limitations](../docs/evidence.md) distinguish sample variation, reference noise and development selection.

| File | What it holds and backs |
| --- | --- |
| [headline.json](headline.json) | `model_samples`: every peptide, four samples, state populations, relaxation and ordered passage-time pairs, plus medians. Backs the 0.26 to 0.39 kT free-energy range, 0.35 kT half disagreement and 5 to 6 overly fast relaxations. `mfpt_by_timescale_all_samples` backs the 83% and 28% passage-time claims. `trade` and `cost` back the GPU-cost curves. `lstar` and `lstar_spearman` hold the reference-length estimate. `oracle` summarises energy replacement. `context_skill` summarises the local-rate record with transitions counted within each path. The historical key `held_out_judged` counts 13 development-test peptides. |
| [value_summary.json](value_summary.json) | Arithmetic from `headline.json`: the estimated 2,900-fold per-ns cost ratio, the 18.5 GPU-second model point, and the shortest sampled MD length matching each error, including the estimated 1,200-fold passage-time cost ratio. No new simulation or fit. Sources and formulae are stored with the values. |
| `evaluation_seed0.json` through `evaluation_seed3.json` | The four original evaluation records, one row per peptide, including state comparisons and auxiliary site diagnostics. The headline file refits the main comparisons from saved paths; auxiliary site metrics that flatten independent paths are not used for the README claims. |
| [references/](references/)`<PEPTIDE>.json` | All 30 state-definition records; `states_ok` identifies 16 accepted models. Accepted records include populations, main states, relaxation, passage times, half comparisons and shuffled-time/doubled-clock controls. These back the selection counts and 0 of 16 reference-half pairs meeting every tolerance. |
| [states/](states/)`<PEPTIDE>.npz` | The 16 reference-defined TICA transforms, microstate centres, metastable assignments and lags. These map MD and model conformations onto the same states; they are not model inputs for generation. |
| [dtrajs/](dtrajs/)`<PEPTIDE>.reference.npz` | `half_a` and `half_b`: 249,500 labels each at 10 ps, or 2.495 µs per half. Supports reference noise, state-based errors and the reference-length estimate. |
| [dtrajs/](dtrajs/)`<PEPTIDE>.model_seed<N>.npz` | Four samples for each of 13 peptides. `model` has 200 separate paths of 2,500 labels at 10 ps, totalling 5 µs per sample. Supports the sample spread and all headline accuracy comparisons. Preserve path boundaries. |
| [dtrajs/](dtrajs/)`<PEPTIDE>.trade.npz` | Model state paths at the six evaluated total lengths, named `model_<L>ns`. Together with the reference halves, these regenerate the error-cost table. Each array row is a separate path. |
| [trade.json](trade.json) | Original per-peptide error-versus-length records for MD and model, including infinite errors when states are missing. `headline.json` contains the refitted medians used in the README. |
| [oracle.json](oracle.json) | Per-peptide original-model, MD-energy replacement and reference-half errors. Backs the free-energy change from 0.26 to 0.10 kT and passage-time change from 1.87 to 2.11; this model sample differs from the four headline samples. |
| [barriers.json](barriers.json) | Per-transition MD event counts, MD/model/pooled symmetric log rates, learned correction and bound saturation. The pooled baseline uses all 30 test peptides. Summary filtering requires at least 20 MD events and finite rates; slow means `G_md < -3`. The final summary has 264 eligible transitions and 14 slow transitions, with model RMS log-rate errors of 0.39 and 0.61 against pooled-baseline errors of 0.45 and 0.48, respectively. |
| [cost/md_implicit_t4.jsonl](cost/md_implicit_t4.jsonl) | MD throughput at each tested concurrency. `agg` is total ns/day per T4; the best value, 4,009, gives 21.6 GPU-s/ns. |
| [cost/model_t4.json](cost/model_t4.json) | ADKH timing for 1 µs over 100 paths with a sibling bundle: setup, sampling, torsion/atom output and 0.0074 GPU-s/ns. This is the scaling measurement, not a separate timing of every plotted length. |
| [cost/model_cpu_gcde.json](cost/model_cpu_gcde.json) | One end-to-end 1 µs GCDE generation on an Apple M4 CPU, including XTC writing, in 1.8 s. |
| [landscapes/](landscapes/)`<PEPTIDE>.npz` | Matched TICA coordinates, metastable labels and backbone phi/psi for all 13 atlas panels. Every 25th frame is retained: 0.25 ns spacing. `md_*` covers the post-equilibration reference; `model_*` covers a separate seed-100 sample with 200 paths. Missing terminal angles are NaN. The atlas colours show model probability per bin, with MD probability contours on the same grid. |

NPZ files are NumPy archives. JSON non-finite values are `Infinity`; retain them as infinite errors, not zeros or discarded observations. Dataset-derived files retain the [MIT notice](../NOTICE.md). Raw MD coordinates are downloaded separately and are not bundled here.
